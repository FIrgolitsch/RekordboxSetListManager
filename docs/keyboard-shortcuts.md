# Keyboard Shortcuts

---

## File

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New project |
| `Ctrl+O` | Open project |
| `Ctrl+S` | Save project |
| `Ctrl+Shift+S` | Save As |
| `Ctrl+Q` | Quit |

---

## Edit

| Shortcut | Action |
|---|---|
| `Ctrl+Z` | Undo |
| `Ctrl+Y` | Redo |

---

## Tracks

| Shortcut | Action |
|---|---|
| `Ctrl+T` | Add track to the selected section |
| `Delete` | Remove selected track(s) |
| `Ctrl+F` | Focus the search / filter box |

---

## Sections

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+A` | Add section |

---

## macOS note

On macOS, `Ctrl` maps to the **Command (⌘)** key in the standard Qt key sequences.  So `Ctrl+S` is `⌘S`, `Ctrl+Z` is `⌘Z`, and so on.
