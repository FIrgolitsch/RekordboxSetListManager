# Rekordbox Set List Manager — User Documentation

**Rekordbox Set List Manager** is a desktop DJ set-planning tool.  Import playlists from Spotify or Tidal, match tracks against your local Rekordbox library, organise them into colour-coded sections, and export a complete Rekordbox XML playlist ready to load on a CDJ.
